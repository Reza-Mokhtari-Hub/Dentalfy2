# آکادمی تخصصی دندانپزشکی دنتالفای (Dentalfy)

پلتفرم تمام‌عیار آموزش و انتشار محتوای تخصصی دندانپزشکی، طراحی و پیاده‌سازی‌شده به صورت Full-Stack برای دانشجویان، پژوهشگران، نویسندگان و اساتید علوم دندانی.

این پروژه با هدف یکپارچه‌سازی مقالات مرجع بالینی، دوره‌های آموزشی ساختارمند، بانک آزمون‌ها، کتابخانه اسناد پزشکی و پنل‌های مدیریتی چندنقشه، با تمرکز کامل بر رابط کاربری راست‌به‌چپ (RTL) و تجربه مطالعه روان توسعه داده شده است.

---

## ویژگی‌ها و امکانات کلیدی

### 1. معماری چندنقشه و کنترل دسترسی (RBAC)
سیستم احراز هویت و سطح دسترسی به صورت تفکیک‌شده برای چهار نقش اصلی طراحی شده است:
- **مدیر کل (Admin / RMO):** مدیریت کامل کاربران، تایید یا رد درخواست‌های عضویت نویسندگان، بازبینی و انتشار مقالات در صف انتظار، مدیریت دوره‌ها، تنظیمات ظاهری و متنی سایت، مشاهده لاگ‌های سیستم و آنالیتیکس.
- **ویراستار (Editor):** دسترسی به بازبینی علمی مقالات، مدیریت دیدگاه‌ها و ویرایش محتوای دوره‌ها بر اساس مجوزهای تخصیص‌یافته.
- **نویسنده (Author):** دسترسی به ویرایشگر بلاکی اختصاصی برای تدوین مقالات بالینی، ارسال پیش‌نویس یا ثبت برای تایید نهایی و پیگیری وضعیت انتشار.
- **دانشجو / کاربر (Student):** ثبت‌نام و تایید ایمیل با کد یکبار مصرف (OTP)، مطالعه مقالات و دوره‌ها، پیگیری پیشرفت تحصیلی، شرکت در آزمون پایان دوره، نشانه‌گذاری (Bookmark) و تاریخچه مطالعه.

### 2. ویرایشگر بلاکی اختصاصی و رندرینگ بالینی
- پشتیبانی از بلوک‌های متنوع محتوایی شامل تیترها، متن‌های ترکیبی (فارسی و لاتین)، تصاویر با آپلود مستقیم روی Cloudinary، ویدیوها، نقل‌قول‌های علمی، لیست‌های شماره‌گذاری‌شده و فایل‌های PDF مرجع.
- رندر اختصاصی محتوای بالینی و جداول/بلوک‌های ساختاریافته در صفحه جزئیات مقاله (`ClinicalHtmlRenderer`).

### 3. سیستم جامع آموزش و آزمون
- **مدیریت دوره‌ها و سرفصل‌ها:** تعریف دوره‌های تخصصی با سرفصل‌های مجزا و اتصال مستقیم مقالات مرتبط به هر دوره.
- **آزمون پایان دوره (Quiz):** طراحی آزمون‌های چهارگزینه‌ای برای هر دوره همراه با تعیین حد نصاب قبولی.
- **نظرسنجی و پرسش‌وپاسخ دوره (Reviews & QnA):** ثبت دیدگاه، امتیازدهی و پرسش سوال از اساتید در صفحه هر دوره با تایید مدیریتی.

### 4. کتابخانه اسناد، مدیریت تعاملات و SEO
- **کتابخانه دیجیتال (Clinical Library):** آپلود و ارائه فایل‌های PDF دستورالعمل‌ها، چک‌لیست‌ها و فرم‌های رضایت‌نامه بالینی.
- **مدیریت دیدگاه‌ها و اعلان‌ها:** سیستم پاسخ‌دهی و تایید دیدگاه‌های مقالات به همراه ارسال اعلان عمومی (Broadcast) برای کاربران.
- **خروجی استاندارد SEO:** تولید خودکار و داینامیک `sitemap.xml`، `robots.txt` و خوراک `rss.xml` بر اساس مقالات منتشرشده در دیتابیس.
- **خروجی کامل سیستم (System Export) و لاگ ممیزی (Audit Logs):** ثبت رویدادهای مهم پنل مدیریت و امکان تهیه بکاپ از ساختار داده‌ها.

## تکنولوژی‌های استفاده‌شده

| بخش | ابزارها و کتابخانه‌ها |
| :--- | :--- |
| **Frontend** | React 19, TypeScript, Tailwind CSS v4, Motion, Lucide React |
| **Backend** | Node.js, Express.js, TypeScript (`tsx`) |
| **Database** | MongoDB, Mongoose ODM |
| **Media & Storage** | Cloudinary (تصاویر، ویدیوها و اسناد PDF) |
| **Email Service** | Nodemailer (ارسال کد تایید OTP از طریق Gmail SMTP) |
| **Build & Deploy** | Vite 6, esbuild, Vercel Serverless Functions |

```text
├── api/
│   └── vercel.ts                 # نقطه ورود Serverless برای استقرار روی Vercel

├── src/
│   ├── components/
│   │   ├── PublicHome.tsx        # صفحه اصلی، لیست دوره‌ها، مقالات، جستجو و کتابخانه
│   │   ├── PostDetail.tsx        # نمایش کامل مقاله، رندر بلاک‌ها، دیدگاه‌ها و نشانه‌گذاری
│   │   ├── ClinicalHtmlRenderer.tsx # کامپوننت نمایش ساختاریافته محتوای بالینی
│   │   ├── PanelDashboard.tsx    # پنل جامع مدیریت، ویراستاری و نویسندگی
│   │   └── StudentPanel.tsx      # پنل دانشجو (پیشرفت، نشانه‌گذاری و تاریخچه)
│   ├── db/
│   │   ├── mongodb.ts            # مدیریت اتصال Pooled به MongoDB
│   │   └── models.ts             # اسکیماها و مدل‌های Mongoose
│   ├── types.ts                  # تایپ‌های مشترک TypeScript
│   ├── App.tsx                   # مسیریابی کلاینت و مدیریت وضعیت کاربر
│   └── main.tsx                  # نقطه ورود React
├── server.ts                     # سرور Express، روت‌های API و میدلور توسعه Vite
├── vercel.json                   # تنظیمات Rewrite برای API و SPA
├── vite.config.ts                # پیکربندی Vite و Tailwind
└── package.json
```

## راه‌اندازی و اجرای محلی (Local Setup)

### پیش‌نیازها
- Node.js نسخه 18 به بالا
- یک دیتابیس MongoDB (لوکال یا MongoDB Atlas)
- حساب Cloudinary برای آپلود فایل‌ها (اختیاری در محیط تست، ضروری برای آپلود مدیا)
- ایمیل و App Password جیمیل برای ارسال کد OTP

### مراحل نصب

۱. دریافت پروژه از گیت‌هاب:
```bash
git clone https://github.com/Reza-Mokhtari-Hub/dentalfy.git
cd dentalfy
```

۲. نصب پکیج‌ها:
```bash
npm install
```

۳. ساخت فایل `.env` در ریشه پروژه و تنظیم متغیرهای محیطی:
```env
MONGODB_URI=mongodb+srv://<username>:<password>@cluster.mongodb.net/dentalfy
CLOUDINARY_URL=cloudinary://<api_key>:<api_secret>@<cloud_name>
GMAIL_USER=your-email@gmail.com
GMAIL_PASS=your-16-char-app-password
APP_URL=http://localhost:3000
```

۴. اجرای پروژه در محیط توسعه:
```bash
npm run dev
```
سرور به صورت پیش‌فرض روی پورت `3000` بالا می‌آید (`http://localhost:3000`).

## اسکریپت‌های پروژه

- `npm run dev` — اجرای سرور Express به همراه Vite در حالت توسعه
- `npm run build` — بیلد کلاینت با Vite و باندل کردن سرور با `esbuild` در مسیر `api/server_bundle.cjs`
- `npm run lint` — بررسی خطاهای تایپ‌اسکریپت (`tsc --noEmit`)
- `npm run clean` — پاک‌سازی فایل‌های خروجی بیلد قبلی

## استقرار (Deployment)

پروژه به گونه‌ای پیکربندی شده که بدون نیاز به تغییر در ساختار کد، مستقیماً روی **Vercel** مستقر شود:
- تمام درخواست‌های `/api/*` و همچنین مسیرهای `/sitemap.xml`، `/robots.txt` و `/rss.xml` از طریق `vercel.json` به تابع `api/vercel.ts` هدایت می‌شوند.
- متغیرهای محیطی بالا را در بخش **Environment Variables** پنل Vercel وارد کرده و دستور بیلد را روی `npm run build` قرار دهید.
